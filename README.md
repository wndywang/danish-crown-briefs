# Tulip Jamonilla — Creator Briefs

Creator-facing briefs for the Danish Crown Philippines "You Make the Moment" campaign.

- `hero.html` — Hero creator (YouTube long-form + Short)
- `tiktok.html` — Macro and Micro creators (TikTok + repost)
- `index.html` — chooser page

Pages are `noindex` so they will not show up in search. Regenerate with
`Projects/Danish Crown/tools/build_briefs.py`.
